## Explicit release limitations

The current hardening work resolves reproducible P0 issues found in the active source, but it does **not** establish full production readiness. The following remain **REQUIRES MANUAL DEVICE TEST**: real provider OAuth Account A/B switching, installed-PWA offline/reconnect, native push permission/receipt/disable across account changes, browser storage recovery, and repeated live AI-provider reliability. The current whole-workspace JSON/localStorage model also remains a documented scale limitation, with an additive migration path in `docs/data-storage-migration-plan.md`.
