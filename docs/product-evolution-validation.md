## Remaining boundaries

The project continues to use a bounded workspace JSON document and an account-scoped local cache. The safe phased migration plan for larger libraries and heavier offline use remains in `data-storage-migration-plan.md`. The review queue and execution coach do not remove that architectural limit.

The Daily Lessons provider may still fall back to a clearly local teaching scaffold when the upstream provider times out. That fallback is intentionally preserved rather than silently presenting remote AI output. Provider reliability, installed-phone push delivery, physical offline behavior, real account switching, keyboard-only flows, and screen-reader behavior remain **REQUIRES MANUAL DEVICE TEST**.
