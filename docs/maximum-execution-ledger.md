## 2026-08-26 continuation evidence

The exact-50 assessment contract is now enforced end to end. `server/learningDrafts.ts` requires exactly 50 questions, validates option indices, and rejects duplicate normalized prompts. `server/studyMaterialSummaries.ts` uses the same exact-50 contract for PDF-derived practice questions while preserving explicit consent and review-before-save/export. `server/assessments.ts` rejects non-50-question quizzes at the trusted-assessment boundary, and `Quizzes.tsx` exposes timed assessment only for 50-question quizzes; shorter learner-created quizzes remain Practice-only.

The Study Assistant now wraps learner context and questions in explicit delimiters, treats those fields as untrusted content, rejects provider output over 8,000 characters, and falls back honestly. The client no longer appends unrelated personalization to direct answers. Focused AI/material/assessment tests pass with 23 tests, TypeScript passes, the audited-file Prettier lint gate passes, the credential scan passes, and the production build passes. The build still reports an approximately 804 kB minified chunk; this remains an engineering optimization item rather than a correctness failure.

## Academic identity and final quality-gate evidence

Official catalogue provenance matching now uses deterministic trimming, repeated-whitespace normalization, and locale-aware case normalization. This prevents presentation-only label differences from turning a verified catalogue subject into a custom subject, while custom learner labels remain custom and are never overwritten. The focused curriculum and QuizDrafts identity tests pass.

The final integrated quality gate passed with **195 test files / 497 tests**, TypeScript, the audited-source Prettier lint gate, credential-literal scan, and production build. The build emits a non-failing approximately 804 kB minified shared chunk warning. Mobile unauthenticated login and shared loading states were visually verified at 390×844; authenticated provider completion, real push delivery, screen-reader traversal, offline multi-device stress, and provider authorization remain explicit manual or external boundaries.

## Independent quality-gate repair evidence

The independent review identified two source-verifiable defects. Material-summary consent was persisted server-side but the client wrote a second local timestamp; the server now returns its authoritative `consentAt`, and the client stores that exact value. Trusted assessment resume pointers were previously keyed only by quiz ID; they are now scoped by authenticated account identity with sanitization, preventing shared-browser account crossover. Regression coverage was added for both contracts.

The post-repair quality gate passed with **196 Vitest files / 502 tests**, TypeScript, deterministic audited-source lint, secret verification, and production build. The build continues to report the known non-failing 804 kB shared client chunk warning; no manual vendor chunking was reintroduced because it previously caused a live bootstrap runtime failure. The active Manus owner-account OAuth denial remains an external provider authorization boundary occurring before Student OS callback.
