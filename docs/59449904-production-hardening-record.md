## Runtime and deployment evidence

The current hardening worktree was built and served through an isolated production process. A browser rendered the unauthenticated Student OS landing interface, populated the root element, and reported no console output. The manifest, service worker, and notification icon assets each returned HTTP 200. The non-static API worker route is source-controlled with an explicit root scope and no-store policy. The public deployment rendered its unauthenticated interface after propagation; its worker endpoint also returned JavaScript with the v8 payload and root-scope authorization. The pre-repair public OAuth start endpoint returned an unexpected 403 Origin response under the proxy; the corrected route is pending its own post-publish endpoint check. The reported mobile OAuth provider flow remains a real-device/provider manual acceptance boundary. These are genuine bootstrap checks, but they are **not** authenticated-user, physical-device, or end-to-end provider acceptance results.
