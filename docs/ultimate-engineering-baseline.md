## Scope discipline

The current JSON-workspace architecture remains a transitional local-first design. This mission does not justify a reckless full normalized-data rewrite. Repairs will be incremental, canonical-schema validated, covered by migrations and regressions, and documented against the existing phased storage plan.

> **Evidence limit.** The deployed database column was directly queried and an isolated disposable-row capacity probe was removed after verification. Unit tests, source checks, controlled probes, and preview screenshots can verify important boundaries; real mobile OAuth, installed-PWA offline reopening, account switching, push receipt, browser variations, and provider reliability remain **REQUIRES MANUAL DEVICE TEST** until observed on physical devices.
